# Vibe — история технического каркаса T0

Реализация/проверки: 10.10.2026; итоговое статическое ревью: 12.10.2026. T0 ACCEPTED по явному ответу владельца «Утвердить T0: технический каркас (рекомендуется)». На завершение первоначальных проверок D1 был PROPOSED; 12.10 владелец отдельно выбрал его и разрешил следующий срез. Полный R2 ещё не завершён.

## Создано

- Backend: ASP.NET Core `net10.0`, один `backend/Vibe.Api`, без внешних пакетов. `GET /health` отвечает `200 application/json {"status":"ok"}`. Адрес по умолчанию — только `127.0.0.1:5080`.
- Web: React 19.3.0, TypeScript 7.0.2, Vite 8.3.4; фиксированные версии и pnpm-lock.yaml. Стартовая русская страница, реальная проверка сервера, повторный запрос, доступные/недоступные состояния. Dev 5173 и preview 4173 — loopback, strictPort, proxy `/health`.
- `global.json`: SDK 10.0.400, latestPatch, без prerelease. Запуск и проверка среды: scripts/dev.ps1 и scripts/check_dev_environment.ps1; инструкция — корневой README.md. Локальные кэши и секреты исключены через .gitignore; Git не инициализирован.

Backend и frontend использовали соответствующие custom роли; записывали код последовательно без Git/worktree. Координатор владел общими файлами, зависимостями/lock-файлом и проверками. Android-инструменты и приложение не создавались.

## Ограничения

Windows sandbox ограничивает доступ к пользовательскому NuGet.Config, npm registry и localhost; pnpm также получил EPERM при realpath web. Разрешённые повторы сборок/загрузки/локальных процессов вне sandbox прошли. Reviewer не переводится вне read-only для обхода этих ограничений. SDK и глобальная конфигурация Codex не изменялись.

Эти ограничения описывают состояние T0 на 10.10.2026: health проверял процесс; PostgreSQL/auth/предметный API тогда отсутствовали, Docker engine был выключен. Состояние после реализации D1 описано в [D1_STATUS.md](D1_STATUS.md). Android Studio/JDK/SDK по-прежнему отложены. Полный аудит безопасности, доступности и производительности не заявляется.
